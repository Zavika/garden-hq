# Phase 5D PWA Install and Offline Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Garden HQ is installable (manifest, original pixel icons), opens offline from a precached app shell, shows a reload toast on updates, and offers an install UI that explains the iPhone Home Screen requirement for web push.

**Architecture:** `vite-plugin-pwa` in `injectManifest` mode builds `src/sw.ts` (Workbox precache + navigation fallback, no runtime caching, so `/api` and the cross-origin Worker are never cached). Registration is in prompt mode and surfaces a toast. Icons and the favicon are generated by a dependency-free Node script (pixel-art grid to PNG via `zlib`) and committed. Platform detection (`isIos`, `isStandalone`) lives in one pure module that 5E (web push) reuses.

**Tech Stack:** Vite 8, `vite-plugin-pwa` 2.0.0 (peer: vite ^8), `workbox-build`, `workbox-window`, `workbox-precaching`, `workbox-routing` (all 7.4.1), React 19, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-10-phase-5-polish-design.md` (sections 5, 9 items 3 and 7).

## Global Constraints

- The service worker NEVER caches `/api/*` or any cross-origin request: no runtime caching routes at all. The cloud-save engine already handles offline; a stale cached sync response would be a data bug.
- New versions install in the background; the user is prompted ("New version available" + Reload). No silent `skipWaiting`/`clientsClaim` that would swap code under an in-flight sync.
- Icons are **original** art (no Hypixel/Minecraft textures): a pixel-art sprout generated in code. Sizes: 192, 512, maskable 512 (safe-zone padding), apple-touch 180. The default Vite favicon is replaced with an original pixel sprout SVG.
- Theme: `theme_color` and `background_color` come from the existing tokens (`--parch` `#f4e4b5` light; dark `#4a3322`). `display: standalone`, `start_url: "/"`, `scope: "/"`, `name: "Garden HQ"`, `short_name: "Garden HQ"`.
- iOS (owner's device): web push works only for sites added to the Home Screen (iOS 16.4+). The install hint must say so in plain words. `platform.ts` must expose `isIos()` (including iPadOS reporting as MacIntel with touch points > 1) and `isStandalone()` (`matchMedia("(display-mode: standalone)")` or `navigator.standalone`) for 5E.
- The service worker is registered only in production builds (`import.meta.env.PROD`), never in tests or `vite dev`.
- Cloudflare Pages: add `apps/web/public/_headers`: `/sw.js` -> `Cache-Control: no-cache`; `/manifest.webmanifest` -> `Content-Type: application/manifest+json`, `Cache-Control: no-cache`.
- `public/sprites/README.md` must not be precached (`globIgnores`).
- Public repo: no secrets, no personal data. TS strict, no `any`, Prettier, typecheck/lint/test/build pass. Real install/offline behaviour is manual and goes in `data/VERIFY.md`.
